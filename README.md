# JobYaari Blog Portal

A responsive Laravel-based blog portal for managing and displaying latest job updates, admit cards, and examination results.

## Features

- Admin Login System
- Create, Edit & Delete Blogs
- Image Upload Support
- AJAX Search & Category Filtering
- Responsive Bootstrap UI
- Session-Based Authentication
- Dynamic Blog Rendering
- Modern UI with Hover Animations

## Tech Stack

- Laravel
- PHP
- MySQL
- Bootstrap
- jQuery AJAX
- HTML/CSS

## Setup Instructions

1. Clone the repository
2. Install dependencies

```bash
composer install
```

3. Configure `.env`
4. Run migrations

```bash
php artisan migrate
```

5. Start server

```bash
php artisan serve
```
